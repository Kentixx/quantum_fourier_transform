# Quantum Fourier Transform
Исследовательский курсовой проект по моделированию квантового преобразования Фурье (QFT) и изучению его применения к обработке изображений на универсальном компьютере.

## О проекте

Цель — изучить принципы QFT, реализовать его программное моделирование с использованием Python и Qiskit, а также исследовать преобразование небольших тестовых изображений и сопоставить результаты с классическими методами обработки DFT/FFT.

Проект ориентирован на экспериментальное исследование, а не на заявление о безусловном преимуществе квантового алгоритма над классическими методами. Отдельное внимание уделяется способу кодирования изображения, подготовке квантового состояния, извлечению результатов и ограничениям моделирования.
